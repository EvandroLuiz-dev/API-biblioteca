# API Biblioteca

API REST para gerenciamento de uma biblioteca.

## Objetivo

Desenvolver uma API para realizar o gerenciamento de livros de uma biblioteca, permitindo o cadastro, consulta, atualização e exclusão de livros.

## Tecnologias

- Node.js
- TypeScript
- Express
- PostgreSQL

## Funcionalidades

- [ ] Cadastro de livros
- [ ] Listagem de livros
- [ ] Consulta de livro por ID
- [ ] Atualização de livros
- [ ] Exclusão de livros

## Instalação

Clone o repositório:

```bash
git clone https://github.com/EvandroLuiz-dev/API-biblioteca.git
```

Entre na pasta do projeto:

```bash
cd API-biblioteca
```

Instale as dependências:

```bash
npm install
```

## Execução

Para executar o projeto em ambiente de desenvolvimento:

```bash
npm run dev
```
